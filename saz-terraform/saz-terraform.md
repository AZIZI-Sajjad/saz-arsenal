# Terraform init

terraform init

# Terraform plan - dry-run
```
terraform plan
terraform plan -var-file="<var_file_name>"
```

# Terraform Appliquer réellement la configuration
```
terraform apply
terraform apply -var-file="<var_file_name>"
```

# Terraform Détruire toutes les ressources créées par le projet
```
terraform destroy
terraform destroy -var-file="<var_file_name>"
```
