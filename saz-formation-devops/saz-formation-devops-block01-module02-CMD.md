## Les 4 dimensions d'un projet
```
[1] Objectifs
[2] Phases
[3] Equipes
[4] Livrables
```

## Phases de gestion de projet
```
 #  PHASE                      LIVRABLE / ACTION
 -  -------------------------  --------------------------
 1  INITIATING                 Project Baseline
 2  PLANNING                   Project Management Plan
 3  EXECUTING                  Manage Project Work
 4  MONITORING & CONTROLLING   Control Project Work
 5  CLOSING                    Report, Learn from Lessons
```
