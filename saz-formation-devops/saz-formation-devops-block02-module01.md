## Relation
```
Lien logique entre deux tables, établi grâce à une clé étrangère qui référence la clé primaire d'une autre table.
```

## Contrainte (CONSTRAINT)
```
Règle imposée à une colonne ou une table pour garantir la validité des données (ex. NOT NULL, UNIQUE, CHECK, PRIMARY KEY).
```

## Requête
```
Instruction SQL adressée à la base de données pour lire ou modifier des données.
```

## Fonction d'agrégation
```
Fonction SQL qui calcule une valeur unique à partir d'un ensemble de lignes (COUNT, SUM, AVG, MIN, MAX).
```

## Intégrité référentielle
```
Principe garantissant qu'une clé étrangère pointe toujours vers une clé primaire existante, évitant les données « orphelines ».
```

## PK : Primary Key (Clé primaire)
```
Colonne identifiant de manière unique chaque ligne d'une table.
```

## SQL (Structured Query Language)
```
Langage de requête structuré. Langage standard utilisé pour interagir avec une base de données relationnelle.
```

## SGBDR
```
Système de Gestion de Base de Données Relationnelle. SGBD organisant les données en tables liées entre elles (ex. MySQL, PostgreSQL, Oracle).
```

## Jointure
```
Opération SQL combinant les lignes de deux ou plusieurs tables sur la base d'une condition commune (généralement PK FK).
```

## FK : Foreign Key (clé étrangère).
```
Colonne d'une table référençant la clé primaire d'une autre table, garantissant l'intégrité référentielle.
```

## DML
```
Data Manipulation Language. Manipule les données (INSERT, UPDATE, DELETE).
```

## Entité
```
Objet ou concept du monde réel représenté dans une base de données sous forme de table (ex. client, produit, commande).
```

## Attributs
```
Une colonne d'une table, représentant une information commune à tous les enregistrements (ex. nom, email).
```

## Enregistrement
```
Une ligne d'une table, représentant une occurrence concrète d'une entité (ex. un client, une commande).
```

## EA (Diagramme Entité Association)
```
Modèle conceptuel représentant les entités d'un système et les relations entre elles. Étape préalable à la création d'une base.
```

## DQL
```
Data Query Language. Interroge les données (SELECT).
```

## NULL
```
Valeur SQL spéciale représentant l'absence de donnée. Différente de 0 ou d'une chaîne vide.
```

## DDL
```
Data Definition Language. Définit la structure des données (CREATE, ALTER, DROP, TRUNCATE).
```

## DCL
```
Data Control Language. Gère les droits et accès (GRANT, REVOKE).
```

## Triggers
```
Procédure SQL qui s'exécute automatiquement en réaction à un événement sur une table (INSERT, UPDATE, DELETE).
```

## MySQL
```
SGBDR open source largement utilisé, qui implémente le langage SQL.
```

## Cloud
```
Modèle d'hébergement où la base de données est stockée sur des serveurs distants accessibles via Internet (ex. AWS, GCP, Azure).
```

## BDD
```
Base de Données. Ensemble structuré de données stockées de manière organisée.
```

## VPS (Virtual Private Server)
```
Serveur virtuel privé loué pour héberger une application ou une base de données.
```

## IA générative
```
Intelligence Artificielle capable de produire du contenu (texte, code SQL…) à partir d'instructions formulées en langage naturel (prompts).
```

## Index
```
Structure interne accélérant la recherche dans une table, à l'image d'un index de livre. Améliore les performances des requêtes de lecture.
```

## Transaction
```
Ensemble d'instructions SQL exécutées comme une unité indivisible : soit toutes réussissent, soit aucune n'est appliquée (principe ACID).
```

## Alias (AS)
```
Nom temporaire donné à une colonne ou une table dans une requête pour améliorer la lisibilité du résultat.
```

## Table
```
Structure de base d'une BDD relationnelle, organisée en lignes (enregistrements) et colonnes (attributs), qui stocke les données d'une même catégorie.
```

## SGBD
```
Système de Gestion de Base de Données. Logiciel permettant de stocker, organiser, sécuriser et interroger des données.
```
