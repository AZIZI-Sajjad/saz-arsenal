## Afficher la version de Node.js
```
node --version
```

## Afficher la version de npm
```
npm --version
```

## Installer Create React App globalement
```
npm install -g create-react-app
```

## Afficher la version de Create React App
```
create-react-app --version
```

## Se placer dans un dossier de projets (Windows)
```
cd <CheminDossier>
```

## Créer un projet React
```
create-react-app <NomProjet>
```

## Se placer dans le dossier du projet
```
cd <NomProjet>
```

## Lancer le serveur de développement React
```
npm start
```

## Installer Homebrew (macOS)
```
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

## Installer Node.js via Homebrew
```
brew install node@18
```

## Installer Create React App avec privilèges (macOS/Linux)
```
sudo npm install -g create-react-app
```

## Créer un dossier de projets React
```
mkdir <CheminDossier>
```

## Créer un projet React avec npx
```
npx create-react-app <NomProjet>
```

## Mettre à jour le cache des dépôts (Linux)
```
sudo apt update
```

## Mettre à niveau les paquets du système (Linux)
```
sudo apt upgrade -y
```

## Installer curl (Linux)
```
sudo apt install -y curl
```

## Ajouter le dépôt NodeSource pour Node.js 18 LTS
```
curl -fsSL https://deb.nodesource.com/setup_18.x | sudo -E bash -
```

## Installer Node.js (Linux)
```
sudo apt install -y nodejs
```

## Corriger les permissions du cache npm
```
sudo chown -R $USER:$USER ~/.npm
```

## Lancer React sur un port différent
```
PORT=<Port> npm start
```

## Afficher les interfaces réseau et adresses IP
```
ip a
```

## Rendre le serveur React accessible sur le réseau
```
HOST=0.0.0.0 npm start
```
