## GCP Trace, profiler, error reporting 
```
Ensemble d’outils GCP pour tracer les requêtes, profiler l’utilisation des ressources (CPU, mémoire), et collecter/rapporter les erreurs d’application (Source GCP)
```

## IaC 
```
Approche consistant à définir et déployer l’infrastructure via du code
```

## FinOps 
```
Approche de gestion et d’optimisation des coûts dans le cloud et l’architecture d’infrastructure, visant à allier l’efficacité et l’émergence des nouvelles technologies et le contrôle minutieux de celles-ci
```

## Bastion 
```
Serveur intermédiaire sécurisé, souvent utilisé comme point d’entrée unique pour accéder aux ressources internes protégées dans un réseau privé, facilitant l’administration et améliorant la sécurité
```

## Microservices 
```
Architecture logicielle qui consiste à diviser une application en une collection de petits services indépendants, chacun étant focalisé sur une tâche spécifique
```

## CNCF - Cloud Native Computing Foundation 
```
Projet issue de la « linux fundations », c’est une organisation créée en 2015 soutenant la promotion de l’utilisation des architectures « cloud » et des outils de déploiements du monde du DevOps. Les principaux acteurs sont Google, Red Hat, IBM…
```

## Black list IP 
```
Liste noire d’adresses IP bloquées ou interdites d’accès à une ressource, infrastructure ou une application
```

## DevSecOps 
```
Extension du métier de DevOps intégrant systématiquement des règles de sécurité (Sec) tout au long du cycle de développement et de déploiement
```

## GCP Monitoring 
```
Outil de Google Cloud pour la surveillance des métriques et des performances des ressources et services déployés sur la plateforme (Source GCP)
```

## Iot 
```
(Internet of Things) : Internet des objets. Réseau d’objets physiques (capteurs, appareils ménagers, voitures…) connectés à Internet, capables de collecter, échanger et traiter des données
```

## ISO 
```
Organisation internationale de normalisation (International Organization for Standardization). L’ISO produit des normes internationales visant à garantir la qualité, la sécurité
```

## Azure Application Insights 
```
Service pour surveiller les performances, détecter les anomalies et analyser l’expérience utilisateur d’une application (Source : Microsoft)
```

## Azure Log Analytics 
```
Service Azure qui collecte et analyse les logs provenant de diverses sources, permettant la création de requêtes et tableaux de bord personnalisés (Source : Microsoft)
```

## GTI 
```
(Garantie de Temps d’Intervention) : C’est un engagement contractuel définissant le délai maximal entre la déclaration d’un incident et le moment où une équipe de support commence à intervenir
```

## Application Monolithique 
```
Application conçue comme un bloc unique, où tous les composants (interface, logique métier, accès aux données) sont étroitement couplés. Les évolutions et maintenances sont plus complexes et moins flexibles
```

## KPI 
```
(Key Performance Indicator) : Indicateur Clé de Performance. Mesure permettant d’évaluer l’efficacité, la performance ou le succès d’une application
```

## GTR 
```
(Garantie de Temps de Rétablissement) : Il s’agit d’un autre engagement contractuel qui détermine le délai maximal entre la déclaration de l’incident et le moment où le système est pleinement rétabli
```

## YAML 
```
Format de sérialisation de données lisible par l’homme, souvent utilisé pour les fichiers de configuration avec Ansible et d’autres
```

## JSON 
```
(JavaScript Object Notation) : Format de données textuel léger, utilisant une structure clé-valeur et des tableaux, souvent utilisé pour les échanges de données entre serveurs et navigateurs ou microservices
```

## CI 
```
(Continuous Integration) : Intégration Continue. Processus de développement logiciel dont les mise à jour du code sont fréquentes, intégrées et testées automatiquement, pour détecter les anomalies et reproduire le schéma d’intégration
```

## Azure Monitor 
```
Service unifié de surveillance pour collecter, analyser et agir sur les données de performances et de diagnostics des ressources Azure (Source : Microsoft)
```

## AWS 
```
(Amazon Web Services) : Plateforme de cloud d’Amazon, offrant une large gamme de services
```

## PRA 
```
(Plan de Reprise d’Activité) : Plan détaillant comment restaurer l’infrastructure et les systèmes critiques après un incident majeur, afin de reprendre rapidement l’activité normale
```

## VNET 
```
(Virtual Network) : Sur Azure, réseau privé virtuel isolé au sein d’un cloud public
```

## UI/UX 
```
(User Interface / User Experience) : UI désigne la conception de l’interface utilisateur (apparence, disposition des éléments graphiques), UX la qualité de l’expérience vécue par l’utilisateur (facilité d’utilisation, fluidité, satisfaction)
```

## IAM 
```
(Identity and Access Management) : Gestion des identités et des accès
```

## Cloud compute 
```
Modèle de prestation de services informatiques basé sur l'accès à des ressources (calcul, stockage, réseau) via Internet, sans gestion directe par l'utilisateur
```

## Site de versionning 
```
Plateforme (ex : GitHub, GitLab) permettant de gérer différentes versions du code source, de suivre l’historique des modifications et de collaborer avec d’autres membres de l’équipe
```

## Scalabilité horizontale 
```
Augmenter la capacité en ajoutant davantage de machines ou instances parallèles
```

## SaaS 
```
Modèle où les applications sont fournies sur Internet en tant que service, accessibles via un navigateur
```

## On-premise 
```
Désigne l’infrastructure, le matériel et les logiciels installés et exécutés au sein des locaux de l’entreprise
```

## Load balancer 
```
Outil ou service répartissant la charge (trafic réseau) entre plusieurs serveurs afin d’améliorer la disponibilité et les performances
```

## IaaS 
```
Modèle de service cloud qui fournit des infrastructures informatiques virtuelles à la demande
```

## Idempotence 
```
c’est une opération qu'on l'applique une ou plusieurs fois et dont on obtient le même résultat. En IaC, appliquer plusieurs fois la même configuration ne modifie pas l’état une fois atteint
```

## Datacenter 
```
Centre de données, un lieu physique regroupant des serveurs et des équipements réseau, gérant l’hébergement et la distribution de données
```

## IDE 
```
(Integrated Development Environment) : Environnement de Développement Intégré. Application regroupant éditeur de code, compilation, débogage, et autres outils pour faciliter le développement logiciel. Ex : Visual studio Code
```

## AWS X-Ray 
```
Service d’AWS permettant la traçabilité, le débogage et l’analyse des performances des applications distribuées, identifiant les goulots d’étranglement (Source AWS)
```

## AD 
```
(Active Directory) : Service d’annuaire de Microsoft Windows permettant de gérer les utilisateurs, groupes, postes de travail et l’authentification au sein d’un réseau d’entreprise (Source Microsoft)
```

## PCA 
```
(Plan de Continuité d’Activité) : Stratégie et ensemble de mesures permettant de maintenir les activités essentielles de l’entreprise en cas de perturbation
```

## VPC 
```
(Virtual Private Cloud) : sur AWS, Réseau privé virtuel isolé au sein d’un cloud public
```

## Free tier 
```
Offre gratuite de base proposée par un fournisseur cloud, permettant de tester ou utiliser une partie des services sans frais pendant une période donnée
```

## Log 
```
journaux : Enregistrements chronologiques des événements, actions, erreurs et informations liées au fonctionnement ou disfonctionnement d’une application ou d’une infrastructure.
```

## CD 
```
(Continuous Delivery / Continuous Deployment) : Livraison et Déploiement Continus. Méthodes pour déployer une application de façon automatisée et continue. Des modifications et ajout de nouvelles fonctionnalités, réduisant ainsi le délai entre les déploiements
```

## GCP Logging 
```
Service GCP pour collecter, stocker et analyser les journaux des applications et des ressources (Source GCP)
```

## Cluster 
```
Ensemble de serveurs (ou nœuds) interconnectés travaillant ensemble afin d’assurer une meilleure disponibilité, performance, et tolérance aux pannes
```

## PaaS 
```
Modèle de service cloud qui offre une plateforme et des outils sans gérer l'infrastructure
```

## Computes 
```
Ressources de calcul mises à disposition pour exécuter des applications
```

## White list IP 
```
Liste blanche d’adresses IP autorisées et confirmées pour avoir accès à une ressource, infrastructure ou une application
```

## GCP 
```
(Google Cloud Platform) : Offre de cloud computing de Google, comprenant des services d’hébergement, de calcul, de stockage
```

## Azure 
```
Plateforme de cloud computing de Microsoft, fournissant de nombreux services intégrés avec l’écosystème Microsoft
```

## AWS Cloudtrail 
```
Service d’AWS enregistrant toutes les actions et appels d’API pour un suivi complet des activités, dans une optique d’audit et de conformité (Source AWS)
```

## Scalabilité verticale 
```
Augmenter la capacité d’un serveur unique en lui ajoutant plus de ressources (processeurs, mémoire, stockage)
```

## DevOps 
```
Métier et culture dont la méthodologie encourageant la collaboration entre développement (Dev) et opérations (Ops) pour accélérer la livraison, améliorer la qualité et la fiabilité des logiciels. La pratique vise à unifier le développement et l’administration d'infra
```

## Provider 
```
(Fournisseur cloud) : Entreprise proposant des services de cloud computing (infrastructure, plateforme, logiciels) accessibles via Internet
```

## RGPD 
```
(Règlement Général sur la Protection des Données) : Réglementation européenne sur la protection des données personnelles des citoyens de l’Union européenne, imposant des obligations légales aux entreprises traitant ces données (Source ANSSI)
```

## AWS Cloudwatch 
```
Service de monitoring et de collecte de métriques d’Amazon AWS, permettant de superviser l’état des ressources et des applications (Source AWS)
```
