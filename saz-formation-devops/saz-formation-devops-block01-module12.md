## Adresse IP
```
Numéro d'identification attribué de façon permanente ou provisoire à chaque périphérique relié à un réseau informatique. C'est grâce aux adresses IP qu'on identifie sur Internet les serveurs et les clients. C'est votre adresse postale sur Internet.
```

## Adware
```
Un adware, logiciel publicitaire ou publiciel est un logiciel qui affiche de la publicité lors de son utilisation.
```

## Antivirus
```
Les antivirus sont des logiciels conçus pour identifier, neutraliser et éliminer des logiciels malveillants (dont les virus informatique ne sont qu'une catégorie).
```

## Attaque opportuniste
```
Une attaque opportuniste est une attaque qui ne vise pas un groupe, une institution ou un individu spécifiquement, mais cherche à diffuser sa menace le plus largement possible pour atteindre un maximum de cibles sans distinction.
```

## Authentification à deux facteurs
```
Méthode d'authentification forte par laquelle un utilisateur peut accéder à une ressource informatique après avoir présenté deux preuves d'identité distinctes à un mécanisme d'identification. Ex. : un mot de passe (que l'usager connaît) et un code PIN reçu par SMS.
```

## Black Hat
```
Un black hat (en français : « chapeau noir ») est, en argot informatique, un hacker mal intentionné.
```

## Catfishing
```
Activité trompeuse dans laquelle une personne crée un avatar ou une fausse identité sur un service de réseau social, ciblant généralement une victime spécifique pour abus ou fraude. Souvent utilisé pour des escroqueries amoureuses sur site de rencontre.
```

## Cheval de Troie
```
Type de logiciel malveillant. C'est un logiciel d'apparence légitime, mais qui contient une fonctionnalité malveillante. Son but est de faire entrer cette fonctionnalité malveillante sur l'ordinateur et de l'installer à l'insu de l'utilisateur.
```

## Client
```
Dans un réseau informatique, un client est le logiciel qui envoie des demandes à un serveur. Lorsque vous accédez à un site internet (un serveur web), le client est votre navigateur: Chrome, Firefox, Edge, Internet Explorer, etc.
```

## Cookie
```
Suite d'informations envoyée par un serveur à un client, que ce dernier retourne lors de chaque interrogation du même serveur sous certaines conditions. Il est équivalent à un fichier texte de petite taille stocké sur le terminal de l'utilisateur.
```

## Cybercrime
```
Un cybercrime est une infraction pénale susceptible de se commettre sur ou au moyen d’un système informatique généralement connecté à un réseau.
```

## Cybersécurité
```
Désigne le rôle de l'ensemble des lois, politiques, outils, dispositifs, concepts et mécanismes de sécurité, méthode de gestion des risques, actions, formations, bonnes pratiques et technologies qui peuvent être utilisés pour protéger les organisations visées.
```

## DNS
```
Le Domain Name System, généralement abrégé DNS, qu'on peut traduire en « système de noms de domaine », est le service informatique utilisé pour traduire les noms de domaine Internet en adresse IP.
```

## Fake news / Infox 
```
Informations mensongères diffusées dans le but de manipuler ou de tromper le public. Prenant une importance singulière à l'ère d'Internet, elles peuvent émaner d'un ou plusieurs individus, médias, homme d'État ou d'un gouvernement.
```

## Fuite de données
```
Peut provenir soit d'une déperdition, soit d'une divulgation inopportune de données, ce qui met en cause la sécurité matérielle et juridique de l'information. Ex. : un site web piraté qui permet à un hacker de récupérer des mots de passe. C'est une fuite de données.
```

## Gestionnaire de mots de passe
```
Type de logiciel/service en ligne qui permet à un utilisateur de  gérer ses mots de passe, soit en centralisant l'ensemble de ses identifiants et mots de passe dans une base de données, soit en les calculant à la demande.
```

## Grey Hat
```
Désigne un hacker ou un groupe de hackers, qui agit parfois avec éthique et parfois non. Ce terme est employé pour désigner ceux qui se situent entre hacker white hat et hacker black hat.
```

## Logiciel espion
```
Logiciel malveillant qui s'installe dans un ordinateur ou autre appareil mobile, dans le but de collecter et transférer des informations sur l'environnement dans lequel il s'est installé, très souvent sans que l'utilisateur en ait connaissance.
```

## Phishing
```
Technique utilisée par des fraudeurs pour obtenir des renseignements personnels dans le but de perpétrer une usurpation d'identité. Consiste à faire croire à la victime qu'elle s'adresse à un tiers de confiance pour qu'elle divulgue des renseignements personnels.
```

## Phrase de passe
```
Désigne un mot de passe d'un nombre important de caractères. Il s'agit d'une phrase complète qui ressemble parfois à une phrase pour des raisons mnémotechniques. Ex. : tulipe-liège-bouteille-bamako
```

## Ransomware
```
Logiciel malveillant qui prend en otage des données. Pour ce faire, un ransomware chiffre des données personnelles puis demande à leur propriétaire d'envoyer de l'argent en échange de la clé qui permettra de les déchiffrer.
```

## Requête
```
La requête est la demande que le client envoie à un serveur, par exemple lorsque vous cherchez à consulter une page web.
```

## Revenge porn
```
Le revenge porn, ou pornodivulgation en français, est un contenu sexuellement explicite qui est publiquement partagé en ligne sans le consentement de la ou des personnes apparaissant sur le contenu dans le but d'en faire une forme de « vengeance ».
```

## Rootkit
```
Ensemble de techniques mises en œuvre par un ou plusieurs logiciels dont le but est d'obtenir et de pérenniser un accès à un ordinateur le plus furtivement possible.
```

## Routeur
```
Un routeur est un équipement réseau informatique assurant le routage des paquets. Son rôle est de faire transiter des paquets d'une interface réseau (votre wifi à la maison par exemple) vers une autre (internet par exemple). Votre "box internet" est un routeur.
```

## Réponse
```
La réponse d'un serveur est le message renvoyé par un serveur au client après traitement de la requête.
```

## Script Kiddie
```
Terme péjoratif désignant les néophytes qui, dépourvus des principales compétences en sécurité informatique, essaient d'infiltrer des systèmes en se servant de programmes efficaces simples d'utilisation mais qu'ils ne comprennent pas.
```

## Serveur
```
Dispositif informatique qui offre des services à un ou plusieurs clients : accès aux informations du World Wide Web, courrier électronique, partage de périphériques, commerce électronique, stockage en base de données, gestion et contrôle d'accès…
```

## Sextortion
```
Type de revenge porn qui emploie des formes non physiques de coercition pour extorquer des faveurs sexuelles ou financières à la victime. Fait référence à la grande catégorie d'exploitation sexuelle dans laquelle l'abus de pouvoir est un moyen de pression.
```

## SMSishing
```
Forme de phishing utilisant des SMS comme vecteurs.
```

## URL
```
Une URL (sigle de l’anglais : Uniform Resource Locator), couramment appelée adresse web, permet d'identifier une ressource sur internet par son emplacement et de préciser le protocole internet pour la récupérer (par exemple http ou https).
```

## Virtual Private Network (VPN) 
```
Réseau privé virtuel permettant de créer un lien direct entre des ordinateurs distants, qui isole leurs échanges du reste du trafic se déroulant sur des réseaux sociaux de télécommunication publics.
```

## Virus
```
Automate autoréplicatif à la base non malveillant, mais aujourd'hui souvent additionné de codes malveillants conçus pour se propager sur d'autres ordinateurs en s'insérant dans des logiciels légitimes, appelés "hôte" à la manière d'un virus biologique.
```

## Vishing
```
Forme de phishing utilisant des appels téléphoniques comme vecteurs.
```

## White Hat
```
Désigne un hacker éthique ou un expert en sécurité informatique qui réalise des tests d'intrusion et d'autres méthodes de test afin d'assurer la sécurité des systèmes d'information d'une organisation. S'oppose au black hat.
```
